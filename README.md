# My Photos

## Pré-requisitos

- Windows 10 ou 11
- Rust stable
- Node.js Active LTS
- WebView2, já incluso no Windows 11
- Build Tools do Visual Studio com o compilador C++ (o linker MSVC)

## Desenvolvimento

Na raiz do repositório:

```
npm install
npm run tauri dev
```

A janela do desktop se chama My Photos.
